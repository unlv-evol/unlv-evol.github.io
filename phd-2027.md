    <section>
      <div class="section-head">
        <div>
          <p class="section-tag">THE OPPORTUNITY</p>
          <h2>Research With EVOL Lab</h2>
        </div>
      </div>

      <p class="lede-block">
        EVOL Lab investigates important challenges in how software systems
        evolve and how developers can be better supported as they build,
        maintain, and change software. We combine empirical studies of
        real-world software development with the design, implementation,
        and evaluation of new methods, techniques, and research tools.
      </p>

      <div class="rq-grid">

        <article class="rq-card">
          <span class="rq-id">Software Evolution</span>

          <h3>Understand How Software Changes</h3>

          <p>
            Study software repositories, related software systems, developer
            activity, and maintenance practices to understand how software
            changes, diverges, and accumulates maintenance challenges over time.
          </p>
        </article>

        <article class="rq-card">
          <span class="rq-id">Dependable Automation</span>

          <h3>Build Methods and Tools</h3>

          <p>
            Develop techniques and research tools that help developers
            discover, adapt, verify, and integrate valuable software changes
            across independently evolving software systems.
          </p>
        </article>

        <article class="rq-card">
          <span class="rq-id">AI-Assisted SE</span>

          <h3>Rethink Developer–AI Collaboration</h3>

          <p>
            Investigate how large language models and coding agents can support
            software engineering while preserving correctness, evidence,
            traceability, and meaningful human oversight.
          </p>
        </article>

      </div>
    </section>


    <section>
      <div class="section-head">
        <div>
          <p class="section-tag">NSF CAREER</p>
          <h2>A Funded Research Program</h2>
        </div>
      </div>

      <p class="lede-block">
        The position is supported by an <strong>NSF CAREER Award</strong>
        focused on dependable reuse and adaptation of software changes across
        long-lived software forks. The research addresses a fundamental
        challenge in modern software development: valuable fixes, improvements,
        and capabilities developed in one software system may also benefit
        related systems, but independently evolving codebases can make those
        changes difficult to identify and safely reuse.
      </p>

      <p class="lede-block">
        The PhD student will contribute to this broader research program while
        developing their own research expertise and scholarly identity. The
        work may involve empirical software engineering, repository mining,
        program analysis, software evolution, AI-assisted software engineering,
        research-tool development, experimentation, and evaluation with
        real-world software systems and developers.
      </p>
    </section>
